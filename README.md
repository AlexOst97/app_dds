# Веб-сервис для управления движением денежных средств (ДДС)

## Цель проекта:

Разработать веб-приложение, которое позволяет пользователямсоздавать, 
редактировать, удалять и просматривать записи о движении денежных средств.

## Описание проекта

Проект представляет собой веб-приложение для учета и управления денежными потоками. А именно:
- Управлять движениями денежных средств (ДДС);
- Просматривать данные в удобной табличной форме с фильтрацией;
- Вести учет статусов, типов, категорий и подкатегорий денежных операций.

## Технологии

- **Backend**: Django, Django REST Framework
- **Frontend**: HTML, Bootstrap, Django Templates
- **Database**: PostgreSQL

## Инструкция по установке:

1. Клонировать с GitHab (*git clone https://github.com/AlexOst97/app_dds/tree/feature/task1*)
2. Установить зависимости (*poetry install*)
